# Pochef

Your kitchen twin. Smart. 

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Lint
npm run lint
```

## Environment Variables

Create a `.env` file with:

```
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-anon-key
```

## Tech Stack

- **Vite**
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Supabase**
- **Radix UI**
- **Lucide React**
